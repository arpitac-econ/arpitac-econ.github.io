# Arpita Chatterjee — personal website

The whole site is a single page: `index.html`. It is published free by GitHub Pages.

## Files

| File | What it is |
|---|---|
| `index.html` | All the text and layout of the site |
| `photo.jpg` | Profile photo (square works best) |
| `cv.pdf` | CV linked from the "Curriculum Vitae" button |

## How to update (all in the browser, on github.com)

**Edit text** (add a paper, news item, etc.)
1. Open this repository on github.com and click `index.html`.
2. Click the pencil icon (Edit). Use ⌘F to find the section; comments in the file mark where things go.
3. To add a paper, copy an existing `<div class="paper"> … </div>` block, paste it, and change the title, link and coauthors.
4. Click **Commit changes**. The site updates in about a minute.

**Replace the CV or photo**
1. Click **Add file → Upload files**.
2. Upload the new file with *exactly the same name* (`cv.pdf` or `photo.jpg`). It replaces the old one.
3. Click **Commit changes**.

**Paper PDFs** can stay in Google Drive. To post a new draft without touching the site, use Drive's
*File information → Manage versions → Upload new version*; the link stays the same.

## Before going live
- Compile the CV on Overleaf, download the PDF, rename it `cv.pdf`, and upload it here.
- Update the "Last updated" date in the footer when you make changes.
